# Security and privacy reports

Do not publish credentials, device dumps, raw journals or account details in issues. Use a minimal synthetic reproduction.

For a suspected vulnerability that could expose credentials or cause unauthorized device changes, use the repository's private vulnerability reporting feature if available. Otherwise open a redacted issue requesting a private contact channel without exploit details or personal data.

CleanTV does not run a hosted service or collect device reports. The initial release is experimental. Review code and plans before use, retain journals, and keep ADB on a trusted network only.
